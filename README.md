# CVMind Platform Homepage

A responsive platform-level homepage concept for CVMind, designed as a separate repository and built with plain HTML, CSS and JavaScript.

## Design direction

- Warm grey/lilac surfaces instead of stark white
- Deep ink typography with a confident cobalt accent and a muted butter-yellow highlight
- Compact section spacing, a restrained number of elements, clear product categories and custom CSS illustrations
- A dedicated introduction to Leo, CVMind's in-product guide for Resume Tailorer, Interview Prep and Proofreading

## Files

- `index.html` — semantic page structure and content
- `style.css` — design tokens, component styling and responsive layouts
- `script.js` — mobile navigation, in-page navigation and footer year

## Run locally

1. Open this folder in VS Code.
2. Start `index.html` with the Live Server extension, or open the file directly in a browser.
3. Test at desktop, tablet and mobile widths.

## Before production

- Confirm individual tool routes with the CVMind team. Links for Resume Builder, AI Job Finder, CVMind Code, Cover Letter Builder, About, Pricing and Contact use current public URLs; some interview-related links currently point to the Leo section or pricing until their exact destination is confirmed.
- Replace the text-based CVMind mark with the official logo asset if provided.
- Connect the new repository to the intended domain/subdomain or merge the homepage into the production app after approval.
- Check keyboard focus, mobile navigation, and all destinations before deploying.
